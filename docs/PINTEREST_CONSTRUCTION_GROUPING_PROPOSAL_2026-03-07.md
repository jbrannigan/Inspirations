## Suggested taxonomy implication

The remaining Pinterest items point to four meaningful buckets:

1. `style reference plans`
2. `style reference materials / details`
3. `construction concerns`
4. `maintenance / repair / utility`

That fourth bucket appears repeatedly enough that it may need to become explicit later, instead of forcing those items into either `construction_concern` or `irrelevant`.

## Immediate recommendation

Short-term:

- move the high-confidence plan items to a style-side plan/reference category
- move the obvious noisy items to irrelevant
- keep the true construction items on construction
- leave the maintenance/repair/utility bucket as a flagged design question
